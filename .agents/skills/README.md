# Master Index: Project Agent Skills

This directory contains the 10 domain-specific skills for the **Complete CSS Learning Platform**. Each skill governs a critical aspect of architecture, curriculum, design, and verification.

| Skill | Primary Domain | When to Invoke |
|---|---|---|
| [`css-expert`](./css-expert/SKILL.md) | CSS Specifications & Layout Engines | Authoring lessons, explaining cascade/specificity/box-model, checking W3C standards. |
| [`css-curriculum`](./css-curriculum/SKILL.md) | Pedagogical Design & Lesson Structure | Creating lesson files, writing 18-part lessons, designing exercises and quizzes. |
| [`ui-design`](./ui-design/SKILL.md) | Desktop Mac-Window Architecture | Building UI layouts, cards, toolbars, sidebars, visual hierarchy. |
| [`color-system`](./color-system/SKILL.md) | Warm Amber/Orange Design Tokens | Defining colors, dual-mode contrast, surface neutrals, theme styling. |
| [`typography-system`](./typography-system/SKILL.md) | Font Scales & Monospace Ergonomics | Formatting headings, code readability, line-heights, character limits. |
| [`layout-system`](./layout-system/SKILL.md) | Multi-column & Responsive Layouts | Managing independent scroll columns, breakpoints, mobile drawers. |
| [`code-example-engine`](./code-example-engine/SKILL.md) | Shiki Server-Side Highlighting | Pre-highlighting code blocks, copy interactions, paired preview snippets. |
| [`interactive-playground`](./interactive-playground/SKILL.md) | CSS Lab & Sandbox Execution | Building `/playground`, iframe sandboxing, real-time CSS injection, presets. |
| [`accessibility`](./accessibility/SKILL.md) | WCAG 2.1 AA Compliance & ARIA | Implementing keyboard navigation, focus rings, screen reader landmarks. |
| [`quality-assurance`](./quality-assurance/SKILL.md) | Testing, Linting & Build Verification | Running build gates, broken-link checks, mobile responsiveness tests. |
