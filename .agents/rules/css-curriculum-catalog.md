# CSS Master Curriculum Catalog & Coverage Checklist

This catalog enforces complete coverage across all 21 curriculum categories (A through U) plus advanced modern modules:

- [ ] **Category A: CSS Fundamentals** (Overview, syntax, adding CSS, comments, browser defaults, rendering engine)
- [ ] **Category B: Selectors Mastery** (Universal, type, class, ID, attributes, combinators, pseudo-classes, pseudo-elements, :is, :where, :not, :has)
- [ ] **Category C: Cascade, Inheritance & Specificity** (Cascade origins, cascade layers @layer, specificity formula, inheritance, !important, @scope)
- [ ] **Category D: CSS Values and Units** (Absolute units, relative units, viewport units svh/dvh/lvh, math functions calc, min, max, clamp)
- [ ] **Category E: Box Model** (Content, padding, border, margin, box-sizing, margin collapsing, overflow, aspect-ratio, outline)
- [ ] **Category F: Colors and Backgrounds** (Named, HEX, RGB, HSL, modern OKLCH/Lab, color-mix, gradients, background properties, blend modes)
- [ ] **Category G: Typography** (Font families, web fonts, @font-face, variable fonts, font sizing, line-height, text alignment, writing modes)
- [ ] **Category H: Display and Positioning** (Flow, block, inline, inline-block, flex, grid, static, relative, absolute, fixed, sticky, z-index, stacking contexts)
- [ ] **Category I: Flexbox** (Container properties, items properties, main/cross axes, flex-grow/shrink/basis, gap, practical layouts)
- [ ] **Category J: CSS Grid Architecture** (Grid tracks, lines, cells, areas, template columns/rows, minmax, auto-fit/auto-fill, Subgrid, practical layouts)
- [ ] **Category K: Responsive Design & Container Queries** (Mobile-first, @media, @container size/style queries, fluid typography, responsive images)
- [ ] **Category L: Borders, Shadows and Graphic Effects** (Border-radius, box-shadow, text-shadow, filters, backdrop-filter, clip-path, masks)
- [ ] **Category M: Transforms, Transitions and Animations** (2D/3D transforms, transition timing, keyframes, scroll-driven animations, reduced-motion)
- [ ] **Category N: Pseudo-classes and Pseudo-elements** (User action, form states, structural selectors, ::before, ::after, ::marker, ::file-selector-button)
- [ ] **Category O: Forms and UI Styling** (Inputs, buttons, checkboxes, custom controls, accent-color, appearance, caret-color, focus states)
- [ ] **Category P: CSS Custom Properties** (Variables declaration/use, inheritance, dynamic themes, @property Houdini registration)
- [ ] **Category Q: Modern & Bleeding-Edge CSS** (Native nesting, container queries, cascade layers, subgrid, :has, anchor positioning, view transitions)
- [ ] **Category R: Advanced CSS Architecture & Performance** (BEM, CSS Modules, utility-first, rendering reflows/repaints, containment, content-visibility)
- [ ] **Category S: CSS At-Rules Reference** (@import, @media, @supports, @font-face, @keyframes, @layer, @container, @scope, @property, @starting-style)
- [ ] **Category T: CSS Functions Reference** (Math, color, transform, filter, gradient, shape, counter, environment functions)
- [ ] **Category U: Standardized CSS Property Directory** (Comprehensive searchable property reference with syntax, values, and compatibility)
- [ ] **Specialized Modules:** CSS Houdini, Shadow DOM styling (`::part()`, `::slotted()`), Logical Properties, Multi-column layout, Print CSS.
